# Overview
This PCB project is a power switch PCB for use in 2S Antweight combat robots.

Power is enabled by fastening an M1.6 screw against the PCB surface.
An additional M2 sized hole is provided for mounting.

# Changelog:
## V1.0:
 - First batch of PCBs built and tested.
 - Black PCB with white silkscreen.
 - M3 mounting hole.

## V1.1:
 - Reduced overall PCB size and reduced clearance between components.
 - Replaced Wurth Elektronik SMD standoff with Sinhoo SMD standoff.
 - Downsized M3 mounting hole to M2.
 - Changed current limiting resistor for less blinding LED and downsized to 0603 package.
 - Added fillet to corners of PCB because I can.
